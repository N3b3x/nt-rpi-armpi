## 🚀 How to Use

### **Start the Complete System**
```bash
# Navigate to your ArmPi Mini directory
cd /path/to/your/ArmPi_mini/

# Start everything (all servers + web interface)
python3 ArmPi_mini.py
```

### **What Starts Automatically**
When you run `ArmPi_mini.py`, you now get:

1. **🔧 RPC Server** (port 9030) - Robot control API
2. **📹 MJPEG Server** (port 8080) - Video streaming  
3. **🌐 Modern Web Interface** (port 8000) - **⭐ NEW!**
4. **🤖 Robot Functions** - All existing functionality
5. **📷 Camera System** - Shared across all servers

### **Access the Interface**
- **Modern Web UI**: http://localhost:8000 ⭐
- **Legacy RPC**: http://localhost:9030
- **Legacy MJPEG**: http://localhost:8080
